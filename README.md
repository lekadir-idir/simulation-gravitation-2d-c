# Simulation gravitationnelle 2D en C

Simulation graphique de la gravitation en 2D développée en C avec SDL2. Le projet représente des corps circulaires et visualise l’influence gravitationnelle à travers des lignes jaunes, avec un rendu graphique interactif.
